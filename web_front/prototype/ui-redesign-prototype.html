重构设计要点

  • 暗色侧边栏 (#16181C) — 替代白色侧栏，立刻拉开视觉档次，消除「模板感」
  • 深色促销卡片 — 左侧 3px 品牌强调条，替代渐变填色，更克制
  • 侧边栏分组 — 导航 / 设置 分组小标题，信息层级更清晰
  • 社区卡片 — 左对齐圆形头像 + 更紧凑的信息排版 + 悬停浮现品牌边框
  • 消息中心 — 未读消息有品牌色边框 + 红色圆点，已读淡灰色
  • 面试步骤条 — 胶囊式分段指示器，当前步骤品牌色填充
  • 表单控件 — 自定义选择器，非 Ant Design 默认样式
  • 整体克制 — 更少的圆角、更轻的阴影、更节制的品牌色使用
