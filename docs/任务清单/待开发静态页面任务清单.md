## 四轮：消息详情页（2026-08-10 待开发）

### 11. 消息详情页 ⬜

| 字段 | 内容 |
|------|------|
| **优先级** | P0 |
| **路由** | `/dashboard/messages/:id` |
| **文件路径** | `src/pages/Dashboard/MessageDetail.tsx` |
| **关联修改** | `Messages.tsx` 消息卡片点击 → `navigate(/dashboard/messages/${msg.id})`；`App.tsx` 新增路由 |

#### 设计思路

消息详情页不应该只是一个简单的"内容展示弹窗"，而是需要根据**消息类型**提供差异化的交互体验。当前消息类型有 6 种：`system`（系统通知）、`comment`（评论）、`like`（点赞）、`follow`（关注）、`interview`（面试）、`dm`（私信）。

#### 页面布局结构

```
┌──────────────────────────────────────────────────┐
│  ← 返回   消息详情                                 │  顶部导航栏
├──────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────┐│
│  │  [图标] 消息类型标签  ·  时间                   ││  消息头部
│  │  标题（大字加粗）                                ││
│  └──────────────────────────────────────────────┘│
│                                                    │
│  ┌──────────────────────────────────────────────┐│
│  │  消息正文内容（完整展示，支持换行）                ││  正文区
│  └──────────────────────────────────────────────┘│
│                                                    │
│  ┌──────────────────────────────────────────────┐│
│  │            [ 关联内容卡片 ]                     ││  关联内容区
│  │   (根据消息类型动态展示不同卡片)                  ││  （条件渲染）
│  └──────────────────────────────────────────────┘│
│                                                    │
│  ┌──────────────────────────────────────────────┐│
│  │  [主操作按钮]    [次要操作按钮]                   ││  操作区
│  └──────────────────────────────────────────────┘│
└──────────────────────────────────────────────────┘
```

#### 各消息类型的差异化设计

**1. 系统通知（system）**

```
场景：「面试报告已生成」「欢迎加入面试教练」
正文：完整通知内容
操作区：[查看报告] / [开始面试] 等主操作按钮
关联卡片：无（或展示相关数据摘要）
```

**2. 评论（comment）**

```
场景：「前端小张 评论了你的帖子」
正文：评论内容全文
关联卡片：被评论的帖子摘要卡片（标题 + 前 2 行正文 + 标签）
操作区：[查看帖子] 按钮 → 跳转帖子详情页
```

**3. 点赞（like）**

```
场景：「你的面试报告获得了 3 个点赞」
正文：点赞详情文案
关联卡片：被点赞的内容摘要卡片（报告/帖子缩略信息）
操作区：[查看详情] 按钮 → 跳转对应内容
```

**4. 关注（follow）**

```
场景：「上岸的鱼 关注了你」
正文：关注文案
关联卡片：关注者用户卡片（头像 + 昵称 + 简介 + 关注/回关按钮）
操作区：[查看主页] → 跳转用户主页（预留）
```

**5. 面试（interview）**

```
场景：「新面试邀请」「面试即将开始」
正文：面试相关通知内容
关联卡片：面试信息卡片（公司/岗位/时间等）
操作区：[进入面试] / [查看详情] 按钮
```

**6. 私信（dm）**

> 私信消息不进入通用消息详情页，而是直接跳转到独立的聊天页面（见下方 13. 私信聊天页）。

```
场景：「前端小张 给你发了一条私信」
操作：点击私信卡片 → 直接跳转 /dashboard/messages/chat/:userId 聊天页
      聊天页采用类似 QQ/微信的即时通讯界面，直接展示往返对话并可快速回复
```

## 六、设计规范（统一引用）

所有新页面遵循以下设计规范：

- **色彩**：墨黑 `#0D1117` / 焰橙 `#FF6B35` / 灰白 `#F6F8FA` / 岩灰 `#5F6B7A` / 线灰 `#E1E4E8`
- **圆角**：卡片 `14px` / 按钮 `10px` / 小元素 `6px`
- **卡片**：白色背景 + 1px 边框 `#E1E4E8` + `14px` 圆角
- **按钮**：`btn-flame` 焰橙填充 / `btn-ghost` 透明边框
- **标签**：`tag` / `tag-flame`
- **布局**：后台内容区 `max-w-[700px]` 或全宽，`p-6` 内边距
- **字体**：标题 `font-extrabold` / 正文 `text-sm font-medium` / 辅助 `text-xs text-[#8B949E]`
